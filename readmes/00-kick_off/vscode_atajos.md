# ⌨️ Atajos de Teclado – Visual Studio Code

[⬅️ Volver al README](../../README.md)

> ⚠️ Atajos pensados para **Windows / Linux**.  
> En macOS suele cambiar `Ctrl` por `Cmd`.

📌 **Tip:** Aprender pocos atajos por semana mejora la productividad sin sobrecargar la memoria.

---

## 🧱 Líneas y edición rápida

| Acción | Atajo |
|------|------|
| Mover una línea arriba / abajo | `Alt + ↑ / ↓` |
| Copiar una línea arriba / abajo | `Alt + Shift + ↑ / ↓` |
| Borrar una línea | `Ctrl + Shift + K` |
| Insertar línea debajo | `Ctrl + Enter` |
| Insertar línea arriba | `Ctrl + Shift + Enter` |
| Duplicar línea | `Shift + Alt + ↓` |

---

## 🎯 Selección múltiple y cursores

| Acción | Atajo |
|------|------|
| Seleccionar todas las apariciones | `Ctrl + Shift + L` |
| Seleccionar siguiente coincidencia | `Ctrl + D` |
| Deshacer última selección | `Ctrl + U` |
| Agregar cursor con mouse | `Alt + Click` |
| Selección en bloque (columna) | `Alt + Shift + Click` |
| Seleccionar línea completa | `Ctrl + L` |

---

## 🧠 Navegación y búsqueda

| Acción | Atajo |
|------|------|
| Buscar en el archivo | `Ctrl + F` |
| Buscar en todo el proyecto | `Ctrl + Shift + F` |
| Ir a archivo | `Ctrl + P` |
| Ir a línea | `Ctrl + G` |
| Ir a símbolo | `Ctrl + Shift + O` |
| Volver atrás / adelante | `Alt + ← / →` |
